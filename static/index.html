4. 单点故障评估（断路演练）

先按当前配置完成规划，再选择一条已安装跳线或一条生效中的常态连接模拟断路。 后端保持其他占用状态不变，重新评估全部路由：受影响路由、失效原因、断点端口与仍可用的替代路径如下； 候选清单按受影响路由数量降序排列。

5. 前面板走线排版

为面板分区指定可用走线槽层与固定插孔列位（按从左到右顺序填写插孔对编号）。 系统保持信号拓扑、常态模式与跳线端点不变，为每根跳线分配走线层与左右绕行方向， 按「交叉数最少 → 跨区线数最少 → 同层长度最短」求解，输出每根跳线的层/方向/交叉对与无法避免的冲突。 槽层可写 1, 2 或带容量的 1:6, 2:4（每层每分区容量默认 8）。

分区名插孔列位（对编号，逗号分隔，左→右）可用走线槽层

6. 信号命名一致性审计

为设备端口 / 插孔对 / 已规划跳线 / 路由填写规范信号名与别名（别名选填）。 系统沿设备内部 · 生效常态 · 跳线传播名签，按半常态分流语义归并端点，检测同一连通分量的 互斥名称、别名环、无标签断点与跨路由串线，给出每项问题的最短证据路径 与可采纳的规范名。其中跨路由串线只追溯独立信号源与路由归属、与名签无关：改名不能消警， 只能调整路由规划或断开物理连通。审计只读取规划结果，不修改任何路由 / 常态 / 跳线。
